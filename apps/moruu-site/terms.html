서비스 약관

시행일: 2026년 10월 30일

1. 서비스

moruu는 운영자 한 사람이 자기 콘텐츠를 만들려고 쓰는 개인용 도구입니다. 일반 사용자에게 서비스로 제공하지 않습니다.

2. 사용 범위

운영자 본인의 계정과 본인이 권리를 가진 자료로만 씁니다. 자료에는 대본, 그림, 음악이 포함됩니다. 다른 사람의 계정을 연결하거나, 다른 사람의 자료를 허락 없이 처리하지 않습니다.

3. 외부 서비스

moruu는 다음 외부 서비스를 씁니다. 각 서비스의 약관과 정책을 따릅니다.

  • Google Drive, Google Cloud Text-to-Speech
  • Notion
  • GitHub Actions
  • Telegram

4. 보증 없음

이 도구는 있는 그대로 제공됩니다. 결과물의 정확성이나 계속 사용할 수 있는지를 보증하지 않습니다.

5. 개인정보

데이터 처리는 개인정보처리방침을 따릅니다.

6. 변경

약관을 바꾸면 이 페이지에 시행일과 함께 올립니다.
