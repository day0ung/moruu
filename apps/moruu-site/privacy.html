← moruu

개인정보처리방침

시행일: 2026년 10월 30일

1. 대상

moruu는 운영자 한 사람이 자기 콘텐츠를 만들 때 쓰는 개인용 도구입니다. 운영자 말고는 사용자가 없고, 다른 사람의 개인정보를 모으지 않습니다.

2. Google 사용자 데이터에 접근하는 범위

moruu는 운영자 본인이 허락한 Google 계정에서 Google Drive 권한(https://www.googleapis.com/auth/drive)으로 아래 일만 합니다.

  • Drive의 moruu 폴더와 그 하위 폴더에서 파일 목록을 보고 내려받습니다. 내려받는 파일은 운영자가 올린 그림, 음악, 출처 메모입니다.
  • moruu 폴더 아래에 콘텐츠별 폴더를 만듭니다.
  • 만든 영상과 자막 파일을 그 폴더에 올립니다.

moruu 폴더 밖의 파일은 읽거나 바꾸거나 지우지 않습니다.

3. 보관

  • Google이 발급한 인증 토큰은 두 곳에만 저장합니다: 운영자 PC의 설정 파일, 그리고 운영자의 GitHub 저장소 비밀값(Actions Secrets). 공개된 곳에 저장하지 않습니다.
  • 영상을 만들려고 내려받은 파일은 렌더하는 컴퓨터에 작업용으로만 잠시 둡니다. 운영자의 PC나, 실행이 끝나면 지워지는 GitHub Actions 실행 환경입니다.
  • 원본 파일과 결과 파일은 운영자 본인의 Google Drive에 남습니다.

4. 제공·공유

Google 사용자 데이터를 팔거나 제3자에게 넘기지 않습니다. 광고에 쓰지 않고, AI·머신러닝 모델 학습에도 쓰지 않습니다.

moruu가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 일은 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 정책의 제한적 사용(Limited Use) 요건도 포함합니다.

5. 권한 철회

Google 계정 → 보안 → 서드 파티 액세스에서 moruu의 접근 권한을 언제든 없앨 수 있습니다. 권한을 없애면 moruu는 Drive에 더 이상 접근하지 못합니다.

6. 문의

Google 로그인 동의 화면에 표시된 개발자 이메일로 연락해 주세요.

7. 변경

이 방침을 바꾸면 이 페이지에 시행일과 함께 올립니다.
